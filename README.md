# Color Sorter Firmware

Application firmware listing for a colour-based product sorting conveyor built on
an STM32F103C8T6. Published as a single self-contained web page: open
`index.html` or the GitHub Pages link for this repository.

Course project ACE 391 - Automation and Control Engineering Project 1.
This repository exists to host Appendix A of the project report.

## Notes on the source

The code appears exactly as it was compiled and loaded onto the board. Its
comments are written in Vietnamese without diacritics, the form in which the
firmware was developed; they are kept rather than translated so the listing
matches the source on the device line for line.

Quotation marks in the listing are straight, as a C compiler requires. A word
processor that substitutes curly quotation marks will make the same code fail to
build.

## Hardware

| Item | Part |
|------|------|
| Controller | STM32F103C8T6, 72 MHz from an 8 MHz crystal |
| Colour sensor | TCS34725 on a GY-33 carrier, I2C2 at 100 kHz |
| Diverter | MG996R servo on TIM3 channel 1 |
| Belt drive | 24 V DC gearmotor switched by a relay |
| Rotation | Quadrature encoder decoded by TIM4 |
| Display | Two single-digit seven-segment indicators via SN74HC595 |
| Proximity | E18-D80NK, counting and display only |
